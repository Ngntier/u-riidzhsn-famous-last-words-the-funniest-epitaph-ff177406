This entry is a single tombstone epitaph of famous last words. The joke turns on a double meaning: the developer's last excuse — "It works on my machine" — becomes literal, because the stone itself is his machine now. `main.py` writes the epitaph to `$MAKEFUN_OUTPUT_DIR/entry.txt` and mirrors the sealed gate (UTF-8, one line, 1–150 characters).
